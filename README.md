# Simple Interest Calculator

## Project Overview

The Simple Interest Calculator is a web-based application that calculates the simple interest and total amount based on the principal amount, interest rate, and time period entered by the user.

## Project Details

* **Project Name:** Simple Interest Calculator
* **Project Type:** Web Application
* **Frontend:** HTML, CSS, JavaScript
* **Version Control:** Git and GitHub

## Purpose

The purpose of this project is to provide a simple and easy-to-use calculator for determining the simple interest on an amount of money over a specified period.

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

**Total Amount = Principal + Simple Interest**

## Main Features

* Enter the principal amount
* Enter the interest rate
* Enter the time period
* Calculate simple interest
* Calculate the total amount
* Display the results clearly
